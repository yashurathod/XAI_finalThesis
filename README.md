# XAI for Household Electricity Demand Forecasting

MSc thesis project. Short-term forecasting of household electricity demand,
with the model's behaviour explained rather than left as a black box.

## Data

UCI Individual Household Electric Power Consumption: about 2.07 million
one-minute readings from a single dwelling near Paris, December 2006 to
November 2010. The forecast target is global active power, in kW. The notebook
downloads the archive on first run.

## Method

Feature engineering produces 71 candidate columns: cyclical calendar encodings,
a Fourier seasonal basis, lags from 1 to 1440 minutes, rolling statistics,
first differences, exponentially weighted means, memory-gap terms, and a
Holt-Winters decomposition refitted on a rolling window. An ablation study
removes the Holt-Winters family from the prediction path, leaving 68 features.

The proposed model stacks XGBoost, LightGBM, CatBoost and a random forest.
Out-of-fold predictions are generated by forward chaining, so the combiner
never sees predictions built from future data, and the combiner itself is a
convex blend with non-negative weights summing to one. A bias calibration
fitted on the validation split corrects the mean residual, which would
otherwise dominate the error once forecasts are aggregated to daily or coarser
granularity.

Every feature uses a shift of at least one step, and all splits are
chronological.

## Results

Test split, one-minute resolution, 311,073 observations:

| Model | MAE | RMSE | R2 | MAPE | MASE |
|---|---|---|---|---|---|
| **Proposed ensemble** | **0.0711** | **0.1996** | **0.9451** | **7.70** | **0.0879** |
| XGBoost | 0.0743 | 0.2025 | 0.9435 | 8.23 | 0.0918 |
| Random forest | 0.0771 | 0.2056 | 0.9418 | 8.97 | 0.0953 |
| LASSO | 0.0843 | 0.2140 | 0.9369 | 10.44 | 0.1042 |
| Linear regression | 0.0845 | 0.2140 | 0.9369 | 10.45 | 0.1044 |
| Persistence | 0.0694 | 0.2170 | 0.9351 | 7.53 | 0.0858 |
| k-nearest neighbours | 0.2255 | 0.3434 | 0.8376 | 32.78 | 0.2786 |

Persistence attains the lowest MAE, which is expected: the load is unchanged
across most minutes, so repeating the last reading is close to optimal under an
absolute-error criterion. It loses on the squared-error measures that the
trained models minimise.

Diebold-Mariano tests, with a Newey-West long-run variance and the
Harvey-Leybourne-Newbold small-sample correction, reject equal predictive
accuracy against every reference model at p < 0.001.

Accuracy by native resolution:

| Resolution | R2 | RMSE | MAPE |
|---|---|---|---|
| 1-minute | 0.9451 | 0.1996 | 7.70% |
| 5-minute | 0.7496 | 0.4146 | 39.23% |
| Hourly | 0.9777 | 0.1049 | 7.88% |

## Running it

```bash
pip install -r requirements.txt
jupyter notebook XAI_Electricity_demand_forecast_final.ipynb
```

The notebook runs top to bottom. Expect a long runtime: the hyperparameter
search and the multi-resolution sweep dominate.
